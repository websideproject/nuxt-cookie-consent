# Introduction

`@websideproject/nuxt-cookie-consent` is a GDPR-compliant, intelligent, and highly customizable cookie consent module for Nuxt 3 & 4.

::callout{icon="i-lucide-triangle-alert" color="warning"}
This module provides tools to help you comply with privacy regulations like GDPR, but using it does **not** automatically guarantee compliance. You are responsible for your site's configuration, cookie descriptions, and overall privacy practices. Always consult a legal professional. The author assumes no liability for legal issues arising from its use.
::

## Features

- **GDPR compliant** — granular control, stale-cookie detection, and consent-gated cookie writing.
- **Intelligent banner** — the initial banner only appears if a configured non-essential cookie actually requires it.
- **Dynamic i18n** — fully translatable UI (including cookie categories) with reactive locale switching. Defaults for EN, DE, ES, FR.
- **Fully configurable** — define categories, colors, and text in `nuxt.config.ts`.
- **On-demand consent** — `useRequestConsent` asks for permission just-in-time.
- **Consent-aware cookies** — `useConsentCookie` for effortless, compliant cookie management.
- **Overridable & themeable UI** — components can be styled via config or replaced entirely using Nuxt Layers.
- **Powered by Nuxt Scripts** — exposes consent-based triggers for efficient script loading.

## How it works

1. You declare your cookie **categories** (and optionally the individual cookies inside them) in `nuxt.config.ts`.
2. On first visit, the module decides whether to show the banner based on the `requiresBanner` flags of your non-essential cookies.
3. The user's choices are stored in a `cookie_consent` cookie and exposed through `$consent` and a set of composables.
4. You gate scripts and cookies behind the relevant category using `$consent.triggers`, `useConsentCookie`, and `useRequestConsent`.
