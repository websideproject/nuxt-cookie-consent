# Installation

Install the package:

::code-group
```bash [bun]
bun add -D @websideproject/nuxt-cookie-consent
```
```bash [pnpm]
pnpm add -D @websideproject/nuxt-cookie-consent
```
```bash [npm]
npm install -D @websideproject/nuxt-cookie-consent
```
::

Add it to your `modules`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@websideproject/nuxt-cookie-consent'],
})
```

The module installs [`@nuxt/scripts`](https://scripts.nuxt.com) automatically, so consent triggers are ready out of the box.

## Add the components

Place the components in your layout or `app.vue`:

```vue [app.vue]
<template>
  <div>
    <NuxtPage />
    <CookieConsentBanner />
    <CookieConsentModal />
    <CookieConsentFab />
  </div>
</template>
```

::callout{icon="i-lucide-paintbrush"}
The built-in components are styled with Tailwind CSS and reference `Shadcn*`-prefixed [shadcn-vue](https://www.shadcn-vue.com) components plus an `<Icon>` component. If your app doesn't register those, [override the components](/guide/components) with your own markup — the override pattern is first-class.
::
