# Installation

Install the module and its peer dependency, [`@nuxt/scripts`](https://scripts.nuxt.com) `^1.0.0`:

::code-group
```bash [bun]
bun add @websideproject/nuxt-cookie-consent @nuxt/scripts
```
```bash [pnpm]
pnpm add @websideproject/nuxt-cookie-consent @nuxt/scripts
```
```bash [npm]
npm install @websideproject/nuxt-cookie-consent @nuxt/scripts
```
::

Add it to your `modules`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@websideproject/nuxt-cookie-consent'],
})
```

The module registers `@nuxt/scripts` itself, so `useScript` and the consent triggers work without adding it to `modules`. Requires Nuxt 4.

## Add the components

Place the components in your layout or `app.vue`:

```vue [app.vue]
<template>
  <div>
    <NuxtPage />
    <CookieConsentBanner />
    <CookieConsentModal />
    <CookieConsentFab />
  </div>
</template>
```

::callout{icon="i-lucide-paintbrush"}
The built-in components are styled with Tailwind CSS and reference `Shadcn*`-prefixed [shadcn-vue](https://www.shadcn-vue.com) components plus an `<Icon>` component. If your app doesn't register those, [override the components](/guide/components) with your own markup — the override pattern is first-class.
::
