# Components & overriding

The module ships three globally-registered components:

| Component | Role |
|-----------|------|
| `CookieConsentBanner` | The initial bottom banner shown on first visit (when required). |
| `CookieConsentModal` | The detailed settings dialog (desktop) / drawer (mobile). |
| `CookieConsentFab` | A floating button to reopen settings after a choice is made. |

Add them once, typically in `app.vue`:

```vue
<template>
  <div>
    <NuxtPage />
    <CookieConsentBanner />
    <CookieConsentModal />
    <CookieConsentFab />
  </div>
</template>
```

## External UI dependencies

The built-in components are styled with Tailwind CSS and reference `Shadcn*`-prefixed [shadcn-vue](https://www.shadcn-vue.com) components (`ShadcnButton`, `ShadcnDialog`, `ShadcnDrawer`, `ShadcnAccordion`, `ShadcnSwitch`, `ShadcnTable`, …), an `<Icon>` component, and `@vueuse/core`. If your project provides these, the components work as-is.

If it doesn't, override them — see below.

## Overriding

Thanks to Nuxt's component resolution, you can replace any built-in component by creating a file with the **same name** in your project's `components/` directory:

```
components/
  CookieConsentBanner.vue
  CookieConsentModal.vue
  CookieConsentFab.vue
```

Your version takes precedence. Use the [component composables](/guide/composables#component-composables) to keep all the consent logic while supplying your own markup:

```vue [components/CookieConsentBanner.vue]
<script setup lang="ts">
const { isVisible, acceptAll, customize } = useConsentBanner()
</script>

<template>
  <div v-if="isVisible" class="my-banner">
    <p>
      <template v-for="part in useConsentText('bannerDescription')" :key="part.content">
        <a v-if="part.type === 'link'" :href="part.href">{{ part.content }}</a>
        <span v-else>{{ part.content }}</span>
      </template>
    </p>
    <button @click="customize">{{ useConsentText('customizeBtn')[0].content }}</button>
    <button @click="acceptAll">{{ useConsentText('acceptAllBtn')[0].content }}</button>
  </div>
</template>
```

The `apps/playground` app in this repository uses exactly this pattern with dependency-free overrides — a good starting point.
